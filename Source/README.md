# Nova Launcher · 绿色版（HTML + 本地宿主方案）

极简的 Windows 应用启动页。**双击 `NovaLauncher.bat` 即用**，免安装、免运行时依赖。

## 怎么用

1. 双击 `NovaLauncher.bat`
2. 窗口自动进入**无边框最大化**（铺满工作区，**任务栏照常可见可用**，不是盖住任务栏的全屏），
   里面是你的应用图标；**右上角有三个按钮：最小化 / 最大化（还原）/ 关闭**
3. 点击图标 → 启动对应程序。**被启动的程序会自动显示到最前面**，不会藏在 Nova 窗口后面
   （由宿主在启动后把新窗口推到 z 序最前，并尽力把键盘焦点也一并接过来）
4. 添加应用有四种方式：
   - 点右上角 ⚙ → 「＋ 添加应用」挑选 EXE / LNK
   - 点 ⚙ → 「🔍 从已安装应用添加」，列表**默认按使用频率从高到低**排列，可切换 按安装时间 / 按名称 / 按路径 / 按类型 / 按来源；
     **默认一项都不勾选**，勾选后点「添加选中」批量加入，底部有「全选 / 全不选」以及实时已选计数
     （已添加过的项会置灰并自动被「全选」跳过）
   - 直接把**快捷方式（.lnk）或 EXE** 从资源管理器、**开始菜单**拖进窗口，松手即添加；可一次拖入多个
   - 在图标上**点右键 → 「打开文件位置」**，可跳到该快捷方式所在文件夹（想手工管理时用得上）
5. 拖拽图标调整顺序（**松手即写入 `apps.json`**，刷新／重启后仍是这个顺序；保存失败会提示并把界面拉回真实顺序）
   图标大小滑块（36~160px）；深/浅主题切换；图标**按程序路径**读取，永远与名字一一对应
6. 「每行图标数」可选 **4~12**：窗口放不下这么多列时，列宽会**自动等比压缩**（图标跟着变小），
   不会横向溢出。想在 12 列下不缩图标，把图标大小滑块调小（如 64px）即可
7. **在图标上点右键**会弹出这个小菜单：
   - **打开** —— 与左键点击等价（应用路径失效时该项置灰）
   - **打开文件位置** —— 在资源管理器里选中该快捷方式本体（商店应用没有本地文件，该项置灰）
   - **重命名** —— 菜单原地变成一个输入框（自动聚焦并全选）：回车或「确定」生效，Esc / 「取消」放弃。
     **只改 Nova 里显示的名字，不改磁盘上的快捷方式文件名**；名字为空会被拦下并提示
   - **移除快捷方式** —— 把该图标从 Nova 里去掉。**只删图标记录，不动磁盘上的快捷方式文件**；
     为防误点，第一次点它只会变成「再点一次确认移除」，再点一次才真的移除
8. **设置抽屉 → 「🩺 检查应用有效性」**：一键对所有已添加的应用做体检——
   文件还在不在、`.lnk` 指向的目标是否已被卸载/挪走都会查出来。**全部有效**时只弹一条提示；
   有失效项时面板会列出 名称 / 失效原因 / 路径，可**单独移除**或**全部移除**，
   同时网格与抽屉列表里的失效磁贴会即时标红
9. **关闭窗口即退出**（宿主 25 秒内自动结束，不留后台进程）

## 界面细节

- **连接状态是一个圆点，不是一个词**：标题栏 `NOVA` 右边的小圆点——
  **绿色 = 已连接宿主**（没连接正常时不出任何文字）；**红色 = 未连接**，此时才会亮出「未连接宿主」文字提示，
  并带轻微呼吸闪动以便一眼注意到。鼠标悬停圆点可看到更具体的原因。
  它由页面心跳实时探测（连续 2 次请求失败才判为断连，避免瞬时抖动误报），
  所以宿主中途崩掉也能立刻看出来，而不是等点图标才报错。
- **主界面只有图标和名字**：没有标题、没有说明文字、底部也没有应用数量/排序状态之类的文案。
  某个应用失效时，**该磁贴自己**会标红（红色名字 + 角标），鼠标悬停能看到它的完整路径——
  状态直接来自文件是否存在的真实检测，比一行汇总文字更不会骗人。
- **无边框最大化，顶部只有一条栏**：启动后窗口铺满工作区（**任务栏仍在，可正常使用**），
  系统标题栏与浏览器自己画的那条标题栏都被去掉，屏幕最顶端**只剩页面自己的 `NOVA` 栏**，
  最小化 / 最大化（还原）/ 关闭改由页面右上角提供。
  网页自己控制不了浏览器窗口，所以这三个按钮平时是**通过 `/api/win` 交给宿主**用 Win32 去操作真实窗口的
  （`body:not(.hosted)` 时整组按钮自动隐藏，纯静态打开不会出现死按钮）。
  **关闭键不依赖宿主**：宿主退出（心跳断/崩溃）后点 ✕ 会自动降级为浏览器原生关窗，窗口永远关得掉；
  此时进入降级态，最小化/最大化置灰（浏览器没有原生窗口 API），并有明确文字提示，不再弹「窗口操作失败」。
  点「最大化」按钮即可在「无边框最大化 ↔ 无边框窗口化（居中 1180×780）」之间切换——**任何状态下都不出现系统标题栏**。
- **任务栏图标就是 NOVA 图标**：宿主每次启动会幂等生成开始菜单快捷方式
  `%APPDATA%\Microsoft\Windows\Start Menu\Programs\Nova Launcher.lnk`（内含应用标识与 nova-logo 图标），
  再给浏览器窗口挂上同一标识并强制任务栏重建按钮——任务栏按钮因此显示为独立的「Nova Launcher」
  应用（图标、名称都来自上面的快捷方式），而不是浏览器图标。这条快捷方式可以直接**固定到任务栏**，
  目录挪动后下次启动会自动修正其路径（M28）。
- **右键菜单：图标上是我们自己的菜单，其他地方一律屏蔽**：
  - 在**图标**上右键 → 弹出自绘菜单「打开 / 打开文件位置 / 重命名 / 移除快捷方式」（见上文第 7 条）；
    重命名与移除一样是**菜单原地变身**——重命名变输入框、移除变二次确认，全程不弹系统对话框；
  - 在**其他地方**（空白处、顶部角标、设置面板）右键 → 不弹出浏览器菜单。
  唯一例外是**搜索框**——可编辑文本控件保留原生菜单，否则右键粘贴、拼写检查会一起失效。
  浏览器那个菜单是原生 UI、不在 DOM 中，Edge/Chromium 也没有对应启动开关，因此由页面在
  **capture 阶段**拦 `contextmenu` 实现。
  ⚠ 注意这个捕获阶段的 `stopPropagation()` 会阻断事件继续下行，所以**图标菜单的触发必须写在同一个处理器里**，
  单独给磁贴挂 `contextmenu` 监听器是收不到事件的（见 `nova-launcher.html` 的「图标右键菜单」段）。

## 文件说明

| 文件 | 作用 |
|------|------|
| `..\NovaLauncher.bat` | **唯一入口，在目录根**。双击启动宿主。**必须 UTF-8 无 BOM + CRLF 换行** |
| `NovaLauncher.ps1` | 宿主（本 data\ 目录内）。本地 HTTP 服务 + 图标提取 + 启动程序 + 任务栏图标三件套。**必须 UTF-8 带 BOM** |
| `nova-launcher.html` | 界面（本 data\ 目录内）。由宿主托管，同源调用 `/api/*` |
| `nova-logo.ico` | 应用图标（256/64/48/32/16），与顶栏 Logo 同款。宿主托管在 `/favicon.ico`（标题栏/Alt-Tab 图标），并在启动时经「窗口 AUMID + 开始菜单 `Nova Launcher.lnk` + WM_SETICON」三件套把**任务栏图标**也换成它（M28——单靠 favicon 管不到任务栏） |
| `nova-logo-256.png` | 图标的 256px PNG 版，预览/文档用 |

> 编码要求不是洁癖：PowerShell 5.1 读无 BOM 的 `.ps1` 会按 GBK 解码，中文注释直接导致语法错误；
> cmd.exe 读带 BOM 的 `.bat` 会报错，且中文注释在 LF 换行下会被当成命令执行。

## 数据存放

目录根只有一个 `NovaLauncher.bat` 入口，**其余全部文件（程序本体 + 数据）都在 `data\` 里**（绿色版自包含，整个文件夹拷走即可迁移；由 `NovaLauncher.ps1` 中的 `$DataDir = $ScriptDir` 决定——ps1 在 data\ 里，数据自然落在 data\）：

```
<程序目录>\                     ← 双击这里的 NovaLauncher.bat
├── NovaLauncher.bat            # 唯一入口
└── data\                       # 程序本体 + 全部数据都在这里
    ├── NovaLauncher.ps1        # 宿主
    ├── nova-launcher.html      # 界面
    ├── nova-logo.ico / .png    # 应用图标
    ├── apps.json               # 应用列表：name / path / sort / kind
    ├── settings.json           # 外观：iconSize / cols / theme
    ├── Icons\                  # 图标缓存（PNG）
    ├── runtime.json            # 运行中的端口/token（退出时自动删除）
    ├── host.log                # 运行日志
    └── BrowserProfile\         # 独立浏览器配置，不影响你日常的 Edge/Chrome（靠 --user-data-dir 指定）
```

## 工作原理

```
nova-launcher.html  ── 点击图标 ──▶  fetch /api/launch?i=N&t=TOKEN
        ▲                                      │
        │  同源托管 /  /api/state  /api/icon    ▼
   NovaLauncher.ps1（127.0.0.1 随机端口 HttpListener）──▶ Start-Process 启动真实程序
                                                          └▶ 把新窗口推到最前（z 序 + 尽力给焦点）
```

- 页面由宿主自己托管，因此是**同源访问**，不需要任何 CORS / JSONP 技巧
- 宿主只监听 `127.0.0.1`，所有 `/api/*` 都要带每次启动随机生成的 token
  （防止任意网页从本机发起调用）
- 图标用 `PrivateExtractIcons` 读取，可拿到 256px 大图，按路径 MD5 缓存；
  **宿主启动时会自动预热**——Icons 目录里缺哪张（缓存被删、新尺寸、新加的应用都算），
  就到应用实际位置提取落盘；`.lnk` 本体提不出图标时解析到目标 exe 再提；
  补提走主循环空闲节拍分批进行，不阻塞窗口打开，期间页面请求随时插队
- 「从已安装应用添加」由宿主枚举三类来源：开始菜单 `.lnk`（解析真实 exe）、注册表卸载项的 `DisplayIcon`、
  `Get-StartApps`（UWP 商店应用走 `shell:AppsFolder\<AUMID>`，经典应用按其 exe 路径收录），再按「路径 + 名称」去重；
  枚举结果缓存 60 秒，避免每次改排序都全量重扫
- **使用频率**取自 `UserAssist`（值名是 ROT13 编码，偏移 4 处为启动次数）加上
  `FeatureUsage\AppSwitched / AppLaunch` 的计数；**安装时间**优先取注册表卸载项的 `InstallDate`，
  其次取目标 exe 的创建时间，UWP 应用取包安装目录的创建时间（三者都拿不到时显示为空）
- 「添加应用」的文件选择框在 HttpListener 回调之外**单独起一个 STA 线程**弹出：
  HttpListener 回调跑在线程池（MTA）线程上，直接 `ShowDialog()` 会抛 `ThreadStateException`
- **窗口控制走 `/api/win`**（`op=min|max|close|state`）。窗口靠 `EnumWindows` 按**标题 + 浏览器进程名**
  匹配（不能用 `$proc.MainWindowHandle`——Edge 常把新窗口交给已存在的浏览器进程，启动进程会立刻退出）；
  无边框 = 去掉 `WS_CAPTION | WS_THICKFRAME` 后 `SetWindowPos` 铺满**工作区**（`WorkingArea`，任务栏可见），
  **必须带 `SWP_FRAMECHANGED`** 否则样式不生效。最大化是**惰性应用**的（空闲节拍 / 首次拉状态 / 心跳三处各试一次），
  因为首开浏览器要新建 `user-data-dir`，启动阶段死等会把 HTTP 服务一起卡住
- **顶部「浏览器自绘标题栏」是单独一层要处理的**：去掉 `WS_CAPTION` 后仍有一条标题栏，
  它不是 Windows 画的，而是 Chromium 在**客户区顶部自绘**的（页面标题 + 三键），不受 Win32 样式控制、
  也没有开关能关掉（`--disable-windows10-custom-titlebar` 实测无效）。
  做法是把这个窗口**整体上移**该栏高度、高度同步加回（底边不动），那条栏就被顶到屏幕上边缘之外。
  栏高**不写死**：页面把 `window.innerHeight` 报给宿主，宿主按
  `客户区高 − innerHeight × 尺度系数` 反推（系数取决于宿主进程是否 DPI 感知）。
- **启动的程序为什么一定能显示在最前**：宿主是**后台进程**，它拉起的应用拿不到前台资格
  （前台锁只认「当前前台进程」和「刚收到用户输入」的进程），所以新窗口会开在我们这个铺满工作区的
  窗口**后面**。解决办法分两层，别混为一谈：
  - **「显示在最前面」（z 序）不需要任何权限**，所以是可以保证的：把窗口
    `SetWindowPos(HWND_TOPMOST)` 再 `HWND_NOTOPMOST`，它就落在所有非置顶窗口之上
    （只改 z 序，不动前面那条上移偏移）；
  - **「拿到键盘焦点」**才受前台锁限制，属尽力而为：依次尝试 给本线程建消息队列 →
    `AttachThreadInput` 借前台线程资格 → 临时清零前台锁超时（用完还原）→ 仍不行就轻敲一次 ALT。
  新窗口靠**启动前后拍快照取差集**找到，而不是按进程找：`.lnk` 要经 shell 中转、
  商店应用交给 explorer 拉起，`-PassThru` 拿到的进程往往不是真正拥有窗口的那个。
- **拖入的快捷方式是怎么找到真实路径的**：浏览器出于安全**不暴露拖入文件的绝对路径**
  （`webkitGetAsEntry().fullPath` 只给得到文件名，非标准的 `file.path` 只有 Electron/WebView2 之类才提供）。
  所以页面上报的是**文件名**，由宿主在 **用户桌面 / 公共桌面 / 用户与所有用户开始菜单（递归）/
  开始菜单 Programs / 快速启动 / 下载**里建索引按名字找回来，命中优先取 `.lnk`；
  名字对不上时还会退一步按**基名**匹配（拖来 `Chrome.exe`、桌面只有 `Chrome.lnk` 也能接上）。
  索引缓存 60 秒。都找不到时会明确告诉你「已查这几处，可改用『添加应用』手动选择」，而不是静默失败。
  注意：这些目录用 `[Environment]::GetFolderPath()` 取（走 shell API），**不能用 `$env:APPDATA` /
  `$env:USERPROFILE`** —— 某些运行环境下它们是空的，`Join-Path` 会直接抛异常并把请求打成 500。

## 直接打开 HTML 会怎样

双击 `nova-launcher.html` 会进入**演示模式**：用内置示例数据展示界面与交互，
不会执行任何启动动作。此时标题栏的状态点是**红色**并提示「未连接宿主」（因为确实没有宿主），
窗口三键也会自动隐藏。要真正启动程序，请走 `.bat`。

## 常见问题

- **窗口一闪就没了 / 打不开**：看 `data\host.log`
- **图标显示为字符方块**：该 EXE 没有可提取的图标资源，属正常回退
- **图标旁有红色标记 / 设置里显示「路径失效」**：记录的文件路径已失效，可在设置里移除后重新添加
- **从已安装应用列表为空**：仅枚举开始菜单、注册表卸载项和 `Get-StartApps`，若某应用三者都没登记则不会出现，改用「＋ 添加应用」手动选
- **拖进去的快捷方式提示「未找到」**：浏览器不给拖入文件的绝对路径，宿主只能拿文件名去
  桌面 / 开始菜单 / 快速启动 / 下载 这几处找。若你的快捷方式放在别处（比如 D 盘的某个文件夹），
  就会找不到 —— 改用「＋ 添加应用」手动选一次即可，之后一直有效
- **点了图标但程序没到最前**：程序本身已经启动了，只是没能抢到焦点（前台锁限制，见上文）。
  它一定在所有非置顶窗口之上，切一下就有；若某些程序自带「开机静默启动」行为，属该程序自身设定
- **右键菜单没出来**：只有**图标上**才有菜单；空白处右键是被刻意屏蔽的
- **想彻底重置**：删掉 `data\` 下的 `apps.json` / `settings.json` / `Icons` 即可
